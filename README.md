# Учебные работы по веб-разработке

Откройте index.html в браузере. Установка зависимостей для просмотра не нужна, интернет не требуется. Не переносите отдельные HTML без соседних папок: общие изображения, Bootstrap и шрифты лежат в assets.

## Как устроены работы

HTML и CSS можно редактировать в VS Code без сборщика. JavaScript нужен для меню, карусели, модальных окон и сообщения после проверки формы. Серверной части нет: формы проверяют поля и прямо сообщают, что данные не отправлены. В Bootstrap использована локальная версия 5.3.3; внешний вид основан на учебных образцах, классы обновлены под эту версию.

В SASS использованы переменная $list-img-circle с требуемыми именами, миксин flexible, цикл for для четырех шахматных строк и each для пяти круглых блоков. Для пересборки в папке 05-sass выполните npm install, затем npm run build. Для обычного просмотра уже есть готовый CSS.

В 07-git сохранена папка .git. Учебная подпись автора коммитов — Student <student@example.invalid>; глобальные настройки Git и существующие репозитории не менялись. Фактический вывод команд записан в operations.txt. При переносе через архив .git сохраняется. Для проверки: git log --graph --oneline --all и git status.

Итоговый проект — «Крошка и крем», торты на заказ в Нижнем Новгороде. Главная, birthday.html и wedding.html содержат отдельные тексты и иллюстрации. В SEO.md перечислены целевые запросы и реальные конкуренты со ссылками. Частотность Wordstat не измерялась.

## Что требует участия студента

1. Согласовать тему итогового сайта с преподавателем, как требует условие.
2. Задание 3: войти в свою Figma и сохранить копию макета. Удалось получить только публичную миниатюру; структура воспроизведена, но фотографии, размеры и тексты приблизительные. При наличии полного доступа нужно сверить их с макетом.
3. Git: создать репозиторий в своем аккаунте GitHub и опубликовать через Pages. Удаленная публикация и регистрация не выполнены; команды приведены в 07-git/README.md.
4. При необходимости добавить ФИО и группу в материалы для сдачи. Эти данные не были предоставлены.

## Проверка

Страницы проверены в Chromium при ширине 1440 и 390 пикселей. Проверяются загрузка картинок, ошибки JavaScript, горизонтальное переполнение, один H1, ссылки и интерактивные элементы. Итоги — в ПРОВЕРКА.md. Оригинальные файлы на диске D не изменялись.

Источники изображений и библиотек — assets/SOURCES.md. Шрифт Thicker предоставлен в пробной версии: коммерческое использование требует отдельной проверки лицензии.
