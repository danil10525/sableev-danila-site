## Итоговый проект ТехноСезон

Тема — сайт аренды строительной техники. Основная особенность — вкладки «Лето» и «Зима» на главной странице. Летний каталог включает экскаватор, фронтальный погрузчик и каток. Зимний — погрузчик со снежным отвалом, самосвал для вывоза снега и генератор для питания оборудования.

Сайт состоит из четырёх страниц:

1. index.html — главная, сезонные вкладки и каталог.
2. summer.html — техника и описание летних работ.
3. winter.html — техника и описание зимних работ.
4. rent.html — условия аренды и форма заявки.

Главная и страницы сезонов содержат самостоятельные тексты и иллюстрации. На каждой странице один H1. Реализованы карточки, карусель, модальное окно с формой, мобильное меню и адаптивное расположение блоков. Выбор карточки подставляет машину в форму; ориентировочная стоимость рассчитывается по числу смен.

Использованы HTML5, CSS3 и JavaScript без сборки. Векторные изображения выполнены в SVG. Целевые запросы и примеры конкурентов приведены в [SEO.md](08-final/SEO.md).

## Просмотр и исходные файлы

Для локального просмотра достаточно открыть главный index.html в браузере. Общие ресурсы учебных заданий находятся в assets. Итоговый сайт хранит собственные стили, сценарии и иллюстрации в 08-final. Для SASS приложены исходный SCSS и скомпилированный CSS. Bootstrap подключён локально.

Работы 1–6 реализуют учебные требования с отдельными отличиями от изображений-образцов. WAWE выполнен по доступной публичной миниатюре Figma; точное совпадение размеров и фотографий с полным макетом не подтверждено.

Цены и характеристики техники демонстрационные. Формы проверяют поля в браузере и не отправляют заявки. Сайт является учебным проектом.
