# Ресурсы

Учебные изображения котов и леопардов извлечены из приложенных преподавателем образцов. Font Awesome 4.7.0, SVG корзины и пробный шрифт Thicker взяты из предоставленных материалов. Сохранены исходные лицензионные уведомления.

Bootstrap 5.3.3: https://getbootstrap.com/ — локальные официальные CSS и JS через jsDelivr. Лицензионные заголовки сохранены. В заданиях использованы современные классы Bootstrap 5, визуальные варианты повторяют учебные образцы.
