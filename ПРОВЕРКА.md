# Проверка итогового проекта ТехноСезон

Четыре страницы проверены в Chromium при ширине 1440, 768 и 390 пикселей — 12 вариантов. На каждой странице один H1, изображения загружаются, горизонтального переполнения и ошибок JavaScript не обнаружено.

Проверены вкладки «Лето» и «Зима» мышью и клавиатурой, ссылка на страницу выбранного сезона, подстановка машины в форму, расчёт стоимости за 3 смены, отклонение неверного телефона, проверка заполненной формы, закрытие поп-апа клавишей Escape, карусель и мобильное меню. Выполнен визуальный просмотр.

Задания 1–6 в этом обновлении не изменялись. Задание 7 исключено. Проверка не подтверждает точное визуальное совпадение WAWE с полным макетом Figma. Публикация обновления выполняется через GitHub Desktop.
