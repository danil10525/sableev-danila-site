# Работа с Git

Локальная часть упражнения выполнена. В этой папке есть настоящий репозиторий .git и operations.txt с фактическим выводом команд. Выполнены начальный коммит, изменение, откат в отдельном учебном репозитории, оформление, создание ветки, добавление статьи, переключение, слияние и удаление ветки. Имя Student и адрес student@example.invalid служат учебной подписью. Глобальные настройки не изменены.

Публикация не выполнялась: нужны ваш GitHub и имя удалённого репозитория. После создания пустого репозитория выполните, подставив СВОЙ_URL:

```sh
git remote add origin СВОЙ_URL
git push -u origin master
```

Далее в настройках GitHub Pages выберите публикацию из ветки master, папка / (root). Эти шаги зависят от интерфейса GitHub. Не добавляйте университетский proxy дома.

Полная история, включая учебный коммит до отката, доступна в reflog. В Git устанавливать ничего не потребовалось: использован доступный исполняемый файл. Установка программ, регистрация аккаунта и публикация не имитировались.
